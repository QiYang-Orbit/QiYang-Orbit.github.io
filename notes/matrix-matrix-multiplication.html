Matrix–Matrix Multiplication in Neural Network Training

Updated 2026-03-03 · ML Notes
← All Notes

概览

Training deep neural networks involves repeated matrix–matrix multiplications。 你训练一个神经网络时，90% 时间都花在 GEMM（矩阵乘）上 （GEneral Matrix Multiplication，完整定义是 C = αAB + βC，而不是常规的 C = AB）。 这篇笔记从一个最简单的全连接网络出发，解释这些矩阵乘在 forward / backward 中是如何出现的。

1. 一个最简单的全连接网络

假设：

  • 输入图片是 784 维（28×28 MNIST）
  • 第一层 256 个神经元
  • 第二层 128 个神经元
  • 输出层 10 类

第一层的计算：

Z1 = X · W1 + b1
符号 维度
X (batch_size × 784)
W1 (784 × 256)（每个 neuron 都要看全部 784 个输入做加权求和，一共有 256 个神经元）
Z1 (batch_size × 256)

这是标准的矩阵乘（GEMM）。

2. Major operations

▶ Forward pass: Compute activations

Forward 过程可以写成：

Z1 = XW1
A1 = activation(Z1)

Z2 = A1W2
A2 = activation(Z2)

Z3 = A2W3
Output = softmax(Z3)

每一层都是“上一层输出 × 权重矩阵”，所以每一层对应一次 GEMM。 如果有 3 层，forward 就有 3 次矩阵乘。

▶ Backward pass: Compute gradients

1️⃣ 权重梯度：反向传播本质是求梯度，核心公式之一是：

dW = A^T · dZ
(batch × hidden)^T × (batch × next)
= (hidden × batch) × (batch × next)
= (hidden × next)

本质上又是一次矩阵乘。

2️⃣ 误差传播：

dZ_prev = dZ · W^T

同样是矩阵乘。

综上：Forward 每层 1 次 GEMM，Backward 每层 2 次 GEMM。 如果有 L 层，每个 epoch ≈ 3L 次 GEMM，再乘上 batch 数量。 这就是为什么 80%–95% 的时间都花在 GEMM 上。

▶ Weight update: Apply gradient descent

在得到梯度之后，再做参数更新（SGD / Adam 等），这里通常是逐元素运算，相比 GEMM 耗时较少。

3. 修改成 matrix–matrix formulation

最基础、直观但低效的实现是逐样本三重循环：

for sample:
    for neuron:
        for input:
            ...

这是“逐样本计算”。高性能实现会改成一次处理整个 batch：

X(batch × input) × W(input × output)

真正变成一个大的 GEMM 调用，让底层库（如 BLAS/cuBLAS）来吃掉主要计算。

4. BLAS 与高性能 GEMM

BLAS (Basic Linear Algebra Subprograms) 提供高度优化的线性代数算子。 典型的单精度矩阵乘接口是 cblas_sgemm(...)。

内部会做很多优化：

  • tiling（分块）
  • cache blocking
  • loop unrolling
  • SIMD 向量化
  • OpenMP 并行
  • 针对具体 CPU 指令集优化

手写三重循环几乎不可能比这些库更快。

5. 形状示例：为什么是矩阵乘

神经网络训练时，我们不是一次处理一个样本，而是一次处理一整个 batch。 假设：

  • batch = 256
  • input = 784
  • hidden = 128

则：

  • 输入矩阵 X 的维度 = (batch × input) = (256 × 784)
  • 权重矩阵 W 的维度 = (input × hidden) = (784 × 128)

矩阵乘规则：

(256 × 784) × (784 × 128)

中间 784 抵消，得到：

Z = (256 × 128)

也就是 (batch × hidden)。

6. Tensor Cores 与 fused GEMM

Tensor Core 做的不是普通乘法。

它计算的是：

D = A × B + C

不是只算 A × B，而是乘完直接加上 C（fused operation）。 如果分步做：

  1. 先算 A × B
  2. 再加 C

需要：

  • 多一次读写显存
  • 多一次寄存器存储

Tensor Core 把它合成一次硬件操作完成，减少数据搬运，从而显著加速矩阵乘相关的计算。

7. 总结

  • Matrix–matrix multiplications (GEMMs) 主导了深度学习的大部分计算。
  • Tensor Cores 提供高效的混合精度矩阵运算。
  • 结合 cuBLAS 等优化库使用 Tensor Cores，可以显著加速训练与推理。
  • 高效实现（如 BLAS、cuBLAS、Tensor Cores）对高性能训练至关重要。
