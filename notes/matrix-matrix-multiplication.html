Matrix–Matrix Multiplication in Neural Network Training

Updated 2026-03-03 · ML Notes
← All Notes

1. Problem Setup

We consider a fully connected layer with input batch X ∈ ℝB×d_in and weights W ∈ ℝd_in×d_out, producing activations Y = XW. This note focuses on how this matrix–matrix multiplication appears in forward and backward passes of neural network training, and what the shape conventions imply in practice.

2. Forward: GEMM View

In most deep learning frameworks, the forward pass of a dense layer is implemented as a general matrix–matrix multiplication (GEMM). The batch dimension B is treated as the number of rows, while d_in and d_out correspond to input and output feature dimensions. Efficient kernels fuse bias addition and activation where possible.

3. Backprop: dL/dW and dL/dX

Given upstream gradient dL/dY, gradients with respect to W and X can be written as:

  • dL/dW = XT(dL/dY)
  • dL/dX = (dL/dY)WT

Both expressions are again matrix–matrix multiplications, which means backprop reuses the same GEMM primitives as the forward pass, just with transposed operands and different shape conventions.

4. Implementation Notes

  • Be explicit about shape conventions (batch-first vs feature-first) to avoid silent broadcasting bugs.
  • On GPU, cuBLAS and cuDNN provide optimized GEMM kernels that dominate the runtime of dense layers.
  • Micro-batching and mixed precision (FP16/BF16) can significantly change the optimal tiling strategy.
